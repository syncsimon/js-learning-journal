# 📚 Resource Index

Use documentation as the source of truth. Videos are supplementary explanations, not a replacement for writing code.

## Primary reference

- [MDN JavaScript Guide](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide)
- [MDN JavaScript Reference](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference)
- [JavaScript.info](https://javascript.info/)
- [ECMAScript specification](https://tc39.es/ecma262/) — consult when you need precise language details; it is not the easiest first tutorial.

## Practice and testing

- [Vitest Guide](https://vitest.dev/guide/)
- [GitHub Skills](https://skills.github.com/)
- [GitHub Docs: About Git](https://docs.github.com/en/get-started/using-git/about-git)

## STEP-style short lessons and exercises

- [STEP posts index](https://step-12.github.io/posts/)
- [STEP site](https://step-12.github.io/)

Use short explanations, attempt exercises before looking at answers, and revisit difficult ideas later. Do not assume every STEP post covers JavaScript specifically; use the site's teaching approach as a practice model.
